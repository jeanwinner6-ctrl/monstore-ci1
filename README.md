## Getting Started

### Frontend Setup

1. Run `npm install`
2. Copy `.env.example` to `.env` (optional - uses defaults if not present)
3. Run `npm run dev`

### Backend Setup

1. Navigate to server directory: `cd server`
2. Run `npm install`
3. Copy `.env.example` to `.env` (optional - Cloudinary config for image uploads)
4. Run `npm start` or `npm run dev` (for auto-reload)

The backend server will run on http://localhost:3001 by default.

## Features

### Admin & Backend Integration
- **Image Upload**: Support for Cloudinary with fallback to placeholder URLs
- **Products Management**: Full CRUD operations with bulk import
- **Vendor Sourcing**: Private sourcing URLs stored server-side (never exposed publicly)
- **Contact Messages**: Create, read, update, and delete contact messages
- **Seller Applications**: Application management with approval workflow
- **Seller Space**: Seller profile and product management
- **Data Persistence**: All data stored in `server/data.json`
